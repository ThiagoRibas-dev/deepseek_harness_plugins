Kokoro inference: WebGPU (iGPU via Vulkan) vs WASM (CPU)

Serve the model directory and open this page from it, so the browser can fetch the model:
cd ~/.dsh/tts/models/kokoro/1939ad2a8e41 && python3 -m http.server 8000 --bind 127.0.0.1
then open http://127.0.0.1:8000/bench-webgpu.html.

This measures throughput only: the token ids and the style vector are synthetic, because generating real ones needs the phonemizer and tokenizer. Same tensor shapes and the same kernels as real text, so the timing is meaningful; the audio it would produce is not.
